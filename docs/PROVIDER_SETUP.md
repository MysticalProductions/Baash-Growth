# BAASH GROWTH — Communication Provider & Gateway Setup Manual

This document provides step-by-step instructions for provisioning, configuring, and verifying production credentials for all communication gateways integrated into BAASH GROWTH.

---

## 1. SMS Gateway: MSG91 (India DLT Compliant)

BAASH GROWTH dispatches promotional, transactional, and OTP SMS through MSG91 in compliance with Telecom Regulatory Authority of India (TRAI) DLT regulations.

### 1.1 DLT Prerequisites
1. **Entity Registration**: Register the business on an Indian Telecom DLT portal (e.g. Airtel DLT, Jio DLT, or Vilpower). Obtain your **Principal Entity (PE) ID**.
2. **Header / Sender ID**: Register a 6-character alphabetic header (e.g. `BAASHN` or `BAASHG`).
3. **Content Templates**: Submit message templates for approval. Ensure variables use the standard DLT syntax `{#var#}`.

### 1.2 MSG91 Console Configuration
1. Log in to [msg91.com](https://msg91.com).
2. Navigate to **AuthKey** and generate an API key with SMS privileges.
3. Link your approved DLT PE ID and Sender ID in MSG91.
4. Navigate to **Flows** and create a flow mapped to your DLT Template ID.

### 1.3 BAASH Admin Configuration
1. Go to **Super Admin Console > Communication Providers**.
2. Under **SMS Gateway (MSG91)**, enter:
   - `AuthKey`: Your MSG91 API key
   - `Sender ID`: Approved 6-character header
   - `Route`: `4` (Transactional / Service Implicit)
3. Click **Test Provider Connection** to send a diagnostic test SMS.
4. Set status to **Active** and save.

### 1.4 MSG91 Webhook Setup (Delivery Reports)
1. In MSG91 Dashboard > **Webhooks**:
   - URL: `https://growth.baash.in/api/webhooks/sms/msg91`
   - Method: `POST`
   - Event: `Delivery Reports (DLR)`

## 2. WhatsApp Business API: Meta Cloud API

BAASH GROWTH connects directly to the official Meta Cloud API for WhatsApp Business messaging.

### 2.1 Meta Business Manager Setup
1. Create or log in to your **Meta Business Manager** account at [business.facebook.com](https://business.facebook.com).
2. Create a Meta App of type **Business** in [developers.facebook.com](https://developers.facebook.com).
3. Add the **WhatsApp** product to your app.
4. Note your **Phone Number ID** and **WhatsApp Business Account ID (WABA ID)**.

### 2.2 System User & Permanent Access Token
1. Go to **Meta Business Settings > System Users**.
2. Add a System User with Admin privileges.
3. Generate a permanent token with the permissions:
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`

### 2.3 Message Template Approval
1. Navigate to **WhatsApp Manager > Message Templates**.
2. Create templates categorized as `MARKETING` or `UTILITY`.
3. Use variables formatted as `{{1}}`, `{{2}}`.
4. Wait for Meta's automated approval (typically 2 to 15 minutes).

### 2.4 BAASH Admin Configuration
1. In **Super Admin Console > Communication Providers**:
   - Enter `Phone Number ID`
   - Enter `Permanent Access Token`
   - Enter `WABA ID`
2. Run **Test Connection** to verify API handshakes.
3. Set status to **Active**.

### 2.5 Webhook Setup (Delivery & Read Status)
1. In the Meta Developer App Dashboard > **WhatsApp > Configuration**:
   - **Callback URL**: `https://growth.baash.in/api/webhooks/whatsapp`
   - **Verify Token**: Token matching `META_WEBHOOK_VERIFY_TOKEN` in your `.env`
2. Under **Webhook Fields**, subscribe to `messages`.

## 3. Email Gateway: Amazon SES (Simple Email Service)

BAASH GROWTH uses Amazon SES for high-deliverability transactional and marketing emails.

### 3.1 Moving Out of SES Sandbox
1. Open the **Amazon SES Console** in your target AWS region (e.g., `ap-south-1` Mumbai).
2. Request production access to lift the daily quota and remove the verified-recipient restriction.

### 3.2 Domain Identity Verification & DNS Records
1. In SES > **Identities**, select **Create identity > Domain** (`baash.in`).
2. Add the required DNS records in your domain registrar:
   - **Easy DKIM**: Add the 3 CNAME records generated by AWS.
   - **SPF**: Add `v=spf1 include:amazonses.com ~all` as a TXT record.
   - **DMARC**: Add `_dmarc.baash.in` TXT record: `v=DMARC1; p=quarantine; rua=mailto:dmarc-reports@baash.in`.
3. Wait for identity status to change to **Verified**.

### 3.3 IAM Credentials
Create an IAM user with programmatic access and attach the policy:
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ses:SendEmail",
        "ses:SendRawEmail"
      ],
      "Resource": "*"
    }
  ]
}
```

### 3.4 SNS Notifications for Bounces and Complaints
1. Create an Amazon SNS Topic: `baash-ses-notifications`.
2. Create an HTTPS subscription with URL: `https://growth.baash.in/api/webhooks/email/ses`.
3. In SES > **Configuration Sets**, create a configuration set and enable event publishing for **Bounces**, **Complaints**, and **Deliveries** pointing to the SNS topic.

## 4. Payment Gateway: Razorpay

BAASH GROWTH integrates Razorpay for automated credit wallet top-ups.

### 4.1 Razorpay Dashboard Setup
1. Log in to the [Razorpay Dashboard](https://dashboard.razorpay.com).
2. Navigate to **Settings > API Keys** to generate:
   - `Key ID` (e.g. `rzp_test_...` or `rzp_live_...`)
   - `Key Secret`
3. Add these credentials to the backend `.env`.

### 4.2 Webhook Registration
1. In Razorpay Dashboard > **Settings > Webhooks**:
   - **Webhook URL**: `https://growth.baash.in/api/webhooks/razorpay`
   - **Secret**: Set a secure secret matching `RAZORPAY_WEBHOOK_SECRET`
   - **Active Events**: Check `payment.captured` and `payment.failed`.
