# BAASH Design System Tokens & Guidelines

Extracted directly from the official BAASH production website (https://baash.in/).

## 1. Color Palette

### Base & Backgrounds
- **Background (Main)**: `#0A0A0F` — True dark canvas
- **Surface / Dark Bg**: `#12121A` — Sidebar, top navigation, secondary surfaces
- **Card Background**: `#1A1A2E` — Container cards, modals, dropdowns
- **Card Border**: `#2A2A3E` — Subtle border for cards and dividers

### Brand Colors
- **BAASH Purple (Primary)**: `#7B35E8` — Primary brand color, primary buttons, links, active focus
- **Purple Dark**: `#5B21B6` — Hover state for primary buttons
- **Purple Light**: `#9333EA` — Accent glows, secondary badges
- **BAASH Pink (Secondary)**: `#F72585` — Active indicators, badges, highlights, callouts
- **Pink Dark**: `#DB1E74` — Hover state for secondary accents
- **Lavender**: `#EDE9FE`
- **Lavender Dark**: `#C4B5FD`

### Functional & Status Colors
- **Success / Active**: `#0D9488` (Teal), `#14B8A6` (Teal Light)
- **Info**: `#00D4FF` (Cyan)
- **Warning**: `#F97316` (Orange), `#EA580C` (Orange Dark)
- **Destructive / Error**: `#E11D48` / `#D4183D`
- **Suspended / Inactive**: `#717182`

### Text & Neutrals
- **Primary Text**: `#FFFFFF` — Headings, high emphasis text
- **Muted Text**: `#A0A0B8` — Secondary text, descriptions, placeholders
- **Subtle / Border**: `#2A2A3E` — Field borders, horizontal rules

### Brand Gradients
- **BAASH Pink-Purple Gradient**: `linear-gradient(135deg, #F72585 0%, #7B35E8 100%)`
- **Subtle Glow Gradient**: `radial-gradient(circle at 50% 0%, rgba(123, 53, 232, 0.15) 0%, transparent 75%)`

## 2. Typography
- **Font Family**: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Weights**: 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold), 800 (ExtraBold)

## 3. Border Radii & Elevation
- **Cards / Containers**: `16px` (`rounded-2xl`) or `12px` (`rounded-xl`)
- **Inputs & Buttons**: `12px` (`rounded-xl`)
- **Badges & Pills**: `9999px` (`rounded-full`)
- **Card Shadow**: `0 4px 20px -2px rgba(0, 0, 0, 0.5)`
- **Brand Glow**: `0 8px 32px 0 rgba(123, 53, 232, 0.2)`

## 4. Scrollbar Style
- **Width**: `6px`
- **Track**: `#12121A`
- **Thumb**: `#2A2A3E` (hover: `#7B35E8`)
- **Border Radius**: `3px`
